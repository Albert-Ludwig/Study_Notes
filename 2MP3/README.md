# MECHTRON 2MP3 Study Notes

Selected course materials for reviewing C programming and related tools.

- [Lectures](Lectures/) contains the main PDF for each topic, from introduction and C basics through profiling.
- [Examples](Examples/) contains the corresponding source code and supporting files. Topic 11 includes a Makefile and its test files.
- [Practice](Practice/) contains the midterm and exam practice PDFs, question files, and supporting data.

For review, start with functions and recursion, arrays, pointers, strings and file I/O, and data structures. Continue with preprocessing, assembly, Makefiles, and profiling.

Some examples illustrate concepts rather than production-ready code. In particular, the pointer allocation example reads uninitialized memory and the linked-list example does not free its nodes.

The lecture PDFs, examples, and practice materials were selected from [ARCO-Lab/2MP3-CM](https://github.com/ARCO-Lab/2MP3-CM) at commit `bf0e1a6e41bef324ad044ac1b36aa8d09b5b32f1`.
