# 3DX4 — Dynamic Systems and Control

This repository contains study notes and MATLAB examples for McMaster University's 3DX4 course. The course introduces mathematical modelling of physical systems, analysis of their response and stability, and feedback controller design to achieve desired system performance.

The materials cover time- and frequency-domain modelling, block diagrams, time response, stability, steady-state error, and root locus analysis and controller design.

- `Lecture_Notes/`: Course notes.
- `Matlab_Examples/`: MATLAB Live Script examples for system modelling and control analysis.

Course reference: [McMaster Computing & Software course directory](https://www.eng.mcmaster.ca/cas/courses/).
